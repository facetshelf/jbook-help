常见问题

通用

需要注册才能用吗？

不需要。系统支持匿名访问，浏览、阅读、进度、书签和笔记都照常保存。

我的数据存在哪里？

FacetShelf 是在线服务，书库信息、阅读进度、书签、笔记与 AI 会话保存在站点的服务器上，不在本地。上传的私有书只有你自己能看到。

支持哪些浏览器？

建议使用较新版本的 Chrome、Edge、Firefox 或 Safari。双列对照等布局在电脑上效果最好。

需要自己准备 AI 的 API Key 吗？

系统会提供少量 token 用于试用 AI 翻译与 AI 对话；也可以填入自己的大模型 API Key（BYOK）。

书籍与格式

支持哪些格式？

EPUB、MOBI、AZW3、PDF、TXT 格式。

能读有 DRM 保护的书吗？

不能。带 DRM 的电子书无法解析。

为什么 PDF 显示效果不理想？

PDF 是固定版式，解析起来比较困难，目前只能按原版式预览。将来可能会提供PDF的流式重排功能。

上传有大小限制吗？

有。单文件大小与一次批量上传的数量取决于账号档位，超出时会在上传前提示。

AI 功能

翻译要等多久？

取决于范围：跟随阅读几乎即时；整章需要一点时间；整书最久。可以边读边等，已译好的部分会先显示。

为什么有的引用只有边框、没有黄底？

说明 AI 引用的是那一段的意思，做的是概括或改写，原文里没有被逐字使用的句子。详见基于本书提问。

AI 额度用完了怎么办？

当月额度用完后，新的 AI 请求会提示额度不足；阅读、书签、笔记不受影响，已译好的内容仍可查看。详见配额与用量。
