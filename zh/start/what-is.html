认识 FacetShelf

FacetShelf 是一个在浏览器里使用的多语言阅读平台。打开网页就能读书，不需要安装任何软件。

三大能力

  • 电子书阅读器：支持 EPUB、MOBI、AZW3、PDF、TXT 格式；可以上传自己的书籍，也可以读取本机文件夹（客户目录）和网络存储（WebDAV 或 S3）。
  • 多语言阅读平台：把一本书翻译成另一种语言，支持行间对照、仅看译文和双列对照三种版式。
  • AI 辅助阅读：基于这本书的内容回答问题，回答里的引用可以直接跳回原文核对。

你需要准备什么

  • 一个现代浏览器（建议使用电脑浏览器，以获得双列对照等完整排版）。
  • 不需要注册也能浏览和阅读；注册后可以使用更多的功能。
  • 系统会提供少量 token 用于试用 AI 翻译与 AI 对话；也可以填入自己的大模型 API Key（BYOK）。
