S3 存储来源

S3 兼容的对象存储（自建 MinIO、cloudflare R2 Object Storage、各类云厂商的对象存储）可以接入，把桶里的电子书同步到书架。

添加

  1. 点左侧工具栏的「来源管理」，在右侧面板的「网络存储」分区点「+ 添加」。
  2. 协议类型选 S3 Remote。
  3. 填下面的字段。
  4. 点「测试连接」，通过后保存并开始第一次同步。

字段

字段说明
Name显示名称，同步后在目录树中作为根节点。必填。
Endpoint存储服务地址，例如 https://s3.example.com。必填。
Bucket桶名。必填。
Prefix只扫描这个前缀下的文件，作用相当于 WebDAV 的根路径，例如 books/。留空扫描整个桶。
Region区域，默认 us-east-1。
Access Key必填。
Secret Key必填；编辑已有来源时留空表示不修改。

和 WebDAV 的差别

  • WebDAV 用「地址 + 根路径」定位目录；S3 用「Endpoint + Bucket + Prefix」。
  • 其余的测试连接、同步、清理远端已删除的书、书签笔记保留，规则完全一样。

地址限制

  • Endpoint 只接受 http / https，且必须能从公网访问。
  • 局域网或内网地址默认被拒绝，需要管理员在服务端加入白名单。
