WebDAV 来源

NAS、Nextcloud、坚果云、群晖这类支持 WebDAV 的存储，可以在这里接入，把里面的电子书同步到书架。

添加

  1. 点左侧工具栏的「来源管理」，在右侧面板的「网络存储」分区点「+ 添加」。
  2. 协议类型选 WebDAV。
  3. 填下面的字段。
  4. 点「测试连接」，通过后保存。
  5. 保存后开始第一次同步；以后可随时在卡片上点「同步」。

字段

字段说明
名称显示名称，同步后作为目录树里的根节点。
地址WebDAV 服务地址，例如 https://example.com/dav/。必填。
根路径只扫描这个子目录；留空扫描整个服务。
用户名必填。
密码必填；编辑已有来源时留空表示不修改。
超时单位秒，默认 30。
验证 SSL 证书内网自签证书时取消勾选。

同步做了什么

  • 增量同步：只补新增、更新变化的文件，不会清空已有内容。
  • 远程已经删掉的书，会从书架移除。
  • 每本书的身份由「来源 + 路径」决定，路径不变则书签、笔记和阅读进度都保留。
  • 卡片上会显示同步状态、上次同步时间和本次同步了多少本；失败时给出原因。

地址限制

  • 只接受 http / https 地址，而且必须能从公网访问。
  • 局域网地址（如 192.168.x.x）默认被拒绝，需要管理员在服务端加入白名单。
  • 地址填错时保存或同步会提示「无效的连接地址」。

数量限制

单次同步的书籍数量、以及账号能保存的远程书籍总数，都受账号档位限制；超出时会在写入任何数据之前就提示。
