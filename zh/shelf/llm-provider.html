AI 模型设置

AI 翻译和 AI 对话都需要一个大模型服务。可以在这里填入自己的 API Key，按自己的账号和额度调用。

在哪里

  1. 打开书架。
  2. 在左侧工具栏点「设置」。
  3. 右侧面板里找到「AI 模型」。

添加一个模型

  1. 点「+ 添加」。
  2. 选择「类型」，填写下表中的字段。
  3. 保存后点击「测试连接」和「拉取模型」。

字段

字段说明
类型调用协议。下拉里列出服务端支持的类型，常见是 OpenAI 兼容协议（DeepSeek、通义、Kimi、vLLM 等都按这个接）。
名称只用来区分不同配置，随便起，例如「DeepSeek 主账号」。必填。
Base URL厂商的接口地址，按其文档填写，例如 https://api.deepseek.com。必填。
API Key厂商给的密钥。编辑已有配置时留空表示不修改。必填。
模型列表可用的模型名，逗号分隔；手动填，或点「拉取模型」自动获取。
当前模型从模型列表里单选一个，实际调用就用它。
启用关闭后不参与翻译调用。默认模型不能关闭，要先取消默认。
设为默认翻译没有指定模型时优先用它。只有一条配置时不能取消默认。

测试连接与拉取模型

  • 测试连接：用填好的地址和密钥发一次请求，确认能用；同时会探测这个模型支持哪些能力（工具调用、推理、JSON 输出），结果显示在提示里，比如✅ 连接成功（工具✓ 推理✓ JSON✓）。
  • 拉取模型：向服务端索取该密钥可用的模型列表，自动填进「模型列表」，省去手写模型名。
  • 两项都要在配置保存之后才能用。

修改与删除

  • 点卡片上的编辑图标可以改配置；API Key 留空表示保持不变。
  • 删除前会确认。删掉最后一条配置后，AI 翻译与 AI 对话将没有可用模型。
  • 取消某条的「默认」时，如果还有其它配置，会自动把另一条设为默认。

和翻译、AI 对话的关系

这里配置的模型是共用的：AI 翻译和 AI 对话用的是同一条配置。换模型后，两边同时生效。

关于密钥

  • 密钥保存在你的账号下，服务端加密存储。
  • 界面上不会回显完整密钥，只显示是否已保存，所以编辑时无法查看原 Key，只能重新填一次。
  • 换电脑或换浏览器后，配置仍然在账号里，不需要重新填。
