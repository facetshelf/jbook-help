配额与用量

系统会提供少量 token 用于试用 AI 翻译与 AI 对话；也可以填入自己的大模型 API Key（BYOK）。

用量怎么算

  • 翻译与对话都会消耗额度，消耗量取决于处理了多少文字。
  • 整书翻译 ＞ 当前章 ＞ 跟随阅读，范围越大消耗越多。
  • 普通阅读、书签、笔记、搜索不消耗额度。

额度用尽时

  • 发起新的 AI 请求会收到提示，说明本月额度已用完。
  • 已经译好的内容、已经完成的对话不受影响，仍然可以看。
  • 最好的办法是用你自己的 API Key（BYOK）。

怎么省着用

  • 先用「跟随阅读」看几段，确认译文质量再考虑整书。
  • 只是想弄懂一句话时，用划词翻译，比整章翻译省得多。
  • 同一个问题不要反复重问；需要补充时就着上一轮追问。
