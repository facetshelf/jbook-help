Interface Language

The interface language only changes the site's own wording — buttons, menus and messages. It never changes what is inside a book.

Available languages

简体中文, 繁體中文, English, 日本語, 한국어, Deutsch, Español, Français.

Switching

  1. Use the Language dropdown at the top of the side panel — in the reader and on the Shelf. The sign-in page and the landing page have a language picker too.
  2. The interface switches immediately.
  3. Your choice survives a page refresh.

Three things not to confuse

ConceptWhat it affects
Interface languageSite wording: buttons, menus, messages
The book's languageThe content of the book; the interface language never changes it
Translation target languageThe language AI Translation turns a book into
