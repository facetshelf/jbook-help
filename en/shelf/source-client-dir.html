Client Directory

A Client Directory brings e-books from a folder on this computer into the Shelf, without uploading them anywhere first.

Requirements

  • Chrome or Edge 86 or later (the browser's directory access is used).
  • When the browser asks whether to allow access to the folder, you must allow it.

Import

  1. Click Sources in the left toolbar, then find the Client Directory section.
  2. Enter a directory name; it will be shown on the Shelf.
  3. Click Import and choose the folder in the picker.
  4. The browser asks for permission — choose Allow this site to view and copy files. Scanning starts only after you allow it, and supported books join the Shelf with their original folder structure.

Opening books from a Client Directory

  1. Before a book opens, it is uploaded from this computer to the server and parsed.
  2. That is why only the computer holding the files can upload or load them. Once a book has been parsed on the server, other devices can read it.
  3. If the permission is lost (for example after clearing browser data, or on another device), import the directory again from Sources.

The permission stays on this computer

  • The browser's folder permission applies to this browser on this computer only. Another device cannot see the folder.
  • If a permission is lost or expires, click Re-import on that directory in Sources, choose the same folder and allow access.
  • Re-importing does not create duplicates; existing books and bookmarks stay.

Limits

How many books a single import can add, and how many remote books an account can keep, both depend on your plan. You are warned before anything is written.
