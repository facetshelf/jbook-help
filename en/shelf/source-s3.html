S3 Source

S3-compatible object storage — self-hosted MinIO, Cloudflare R2, or a cloud provider's object storage — can be connected here, and the e-books in a bucket can be synced to the Shelf.

Add a source

  1. Click Sources in the left toolbar, then + Add in the Network Storage section.
  2. Choose S3 Remote as the protocol.
  3. Fill in the fields below.
  4. Click Test Connection; save once it succeeds and the first sync starts.

Fields

FieldNotes
NameDisplay name; after syncing it becomes the root node in the contents tree. Required.
Endpoint URLThe storage endpoint, e.g. https://s3.example.com. Required.
BucketBucket name. Required.
PrefixScan only files under this prefix — the equivalent of WebDAV's Root Path, e.g. books/. Leave empty to scan the whole bucket.
RegionRegion; us-east-1 by default.
Access KeyRequired.
Secret KeyRequired; when editing an existing source, leave empty to keep the current one.

How S3 differs from WebDAV

  • WebDAV locates a directory with Server URL + Root Path; S3 uses Endpoint URL + Bucket + Prefix.
  • Everything else works the same: test connection, sync, removing books deleted remotely, and keeping bookmarks and notes.

Address rules

  • The endpoint must be http or https, and must be reachable from the public internet.
  • Local and intranet addresses are rejected by default; an administrator can add them to a server-side allowlist.
