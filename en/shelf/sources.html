Sources

Sources decides where the books on your Shelf come from: a directory on the server, a folder on this computer, or network storage.

Where to find it

  1. Open the Shelf.
  2. Click Sources in the left toolbar.
  3. The Sources panel opens on the right, listing the source types available to you; click the button again to close it.

Four sections

SectionWhat it holds
Upload DirectoryThe directory where the site receives uploaded files, set by an administrator.
Server DirectoryA directory on the server that hosts the site, added by an administrator.
Client DirectoryA folder on this computer; once imported, its books join the Shelf.
Network StorageA directory on WebDAV or S3 storage, synced into the Shelf.

Which sections appear depends on your account: sections you have no access to are hidden.

Which one to use

  • Books are in a folder on this computer — use Client Directory.
  • Books are on a NAS, cloud drive or object storage — use WebDAV or S3.
  • Books are already on the server — use Server Directory (an administrator sets it up).

What they share

  • After an import or a sync, books appear in the contents tree with their original folder structure.
  • Re-importing, refreshing or syncing only updates the file list; it never overwrites titles, authors or favorites you changed by hand.
  • Deleting a network source also deletes the books it synced. Make sure you no longer need them first.
  • Books from a Client Directory or network storage are read only when opened, or during a batch parse. The server keeps only the parsed result.
