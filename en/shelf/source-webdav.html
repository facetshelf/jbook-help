WebDAV Source

Any storage that speaks WebDAV — a NAS, Nextcloud, Jianguoyun, Synology and the like — can be connected here, and its e-books can be synced to the Shelf.

Add a source

  1. Click Sources in the left toolbar, then + Add in the Network Storage section.
  2. Choose WebDAV as the protocol.
  3. Fill in the fields below.
  4. Click Test Connection; save once it succeeds.
  5. The first sync starts right after saving. Later, click Sync on the card whenever you like.

Fields

FieldNotes
NameDisplay name; after syncing it becomes the root node in the contents tree.
Server URLThe WebDAV endpoint, e.g. https://example.com/dav/. Required.
Root PathScan only this subfolder; leave empty to scan the whole server.
UsernameRequired.
PasswordRequired; when editing an existing source, leave empty to keep the current one.
Timeout (s)In seconds; 30 by default.
Verify SSL CertificateUncheck for self-signed certificates on a local network.

What a sync does

  • Incremental: it only adds new files and updates changed ones; nothing already there is cleared.
  • Books deleted remotely are removed from the Shelf.
  • A book is identified by its source + path. As long as the path stays the same, its bookmarks, notes and reading position are kept.
  • The card shows the sync state, the time of the last sync and how many books were synced; failures come with a reason.

Address rules

  • Only http and https addresses are accepted, and they must be reachable from the public internet.
  • Local addresses such as 192.168.x.x are rejected by default; an administrator can add them to a server-side allowlist.
  • If the address is wrong, saving or syncing reports an invalid connection address.

Limits

How many books a single sync can add, and how many remote books an account can keep, both depend on your plan. You are warned before any data is written.
