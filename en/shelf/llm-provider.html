AI Model Settings

AI Translation and AI Chat both need a large language model. Here you can plug in your own API key and call it with your own vendor account and quota.

Where to find it

  1. Open the Shelf.
  2. Click Settings in the left toolbar.
  3. Find AI Model in the right-hand panel.

Add a model

  1. Click + Add.
  2. Choose a Type and fill in the fields below.
  3. Save, then click Test connection and Fetch models.

Fields

FieldNotes
TypeThe calling protocol. The dropdown lists the types the server supports; the common one is the OpenAI-compatible protocol (DeepSeek, Qwen, Kimi, vLLM and others all connect this way).
NameOnly used to tell configurations apart — anything works, e.g. "DeepSeek main account". Required.
Base URLThe vendor's API endpoint, as documented by the vendor, e.g. https://api.deepseek.com. Required.
API KeyThe key issued by the vendor. When editing, leave empty to keep the current key. Required.
Model list (comma-separated)Available model names, comma-separated; type them by hand or click Fetch models.
Current model (single selection)Pick one from the model list; this is the model actually called.
EnabledWhen disabled, the model is not used for translation. A default model cannot be disabled — unset its default first.
Set as defaultUsed first when a translation does not name a model. With only one configuration, the default cannot be unset.

Test connection and fetch models

  • Test connection — sends one request with the address and key to confirm they work. It also probes which capabilities the model supports (tool calling, reasoning, JSON output) and shows the result, e.g. ✅ Connection successful (tools ✓ reasoning ✓ JSON ✓).
  • Fetch models — asks the server for the models this key can use and fills the model list, so you do not have to type names.
  • Both are available only after the configuration has been saved.

Edit and delete

  • Click the edit icon on a card to change the configuration; leaving API Key empty keeps it unchanged.
  • Deleting asks for confirmation. After the last configuration is deleted, AI Translation and AI Chat have no model to use.
  • If you unset one card as default and other configurations exist, another one automatically becomes the default.

Shared with translation and AI Chat

The model configured here is shared: AI Translation and AI Chat use the same configuration. Changing it takes effect in both at once.

About the key

  • The key is stored with your account and encrypted on the server.
  • The full key is never shown again; the interface only says whether one is saved. When editing you cannot read the old key, so enter it again.
  • On another computer or browser the configuration is still in your account; nothing needs re-entering.
