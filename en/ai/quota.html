Quota & Usage

A small token allowance is included for trying AI Translation and AI Chat; you can also plug in your own model API key (BYOK).

How usage is counted

  • Both translation and chat use the allowance; how much depends on the amount of text processed.
  • Whole book > current chapter > translate while reading — the larger the range, the more it uses.
  • Ordinary reading, bookmarks, notes and search use none.

When the quota runs out

  • A new AI request shows a message that this month's quota is used up.
  • Content already translated and conversations already finished are unaffected and stay readable.
  • The simplest fix is to use your own API key (BYOK).

Using less

  • Try Translate while reading on a few passages to judge quality before committing to the whole book.
  • To understand a single sentence, use Translate Selection — far cheaper than a chapter.
  • Do not repeat the same question; add to the previous answer instead.
